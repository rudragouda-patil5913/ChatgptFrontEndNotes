### What is the DOM?

The DOM is a tree-like representation of an HTML document where every HTML element becomes an object (called a node) that JavaScript can access and modify.Dom is created by browser.

- DOM is created by the browser.
- HTML becomes an object tree.
- JavaScript works with DOM objects, not raw HTML.
- Every HTML element becomes a node.
- DOM enables dynamic web pages.

### What is BOM?

The Browser Object Model (BOM) provides JavaScript with objects that represent the browser window and allow interaction with browser features such as navigation, history, storage, timers, and dialogs.

- The Browser Object Model is a collection of browser-provided objects that allow JavaScript to interact with browser features such as the window, navigation, history, timers, storage, and dialogs. The global window object is the root of the BOM, and objects like document, location, history, and navigator are accessible through it.

### Explain the Rendering Pipeline?

The browser parses HTML into the DOM Tree and CSS into the CSSOM Tree. These are combined to create the Render Tree. It then calculates the layout (positions and sizes), paints pixels, composites different layers, and finally displays the result on the screen.

Browser cannot display HTML directly.
HTML → DOM.
CSS → CSSOM.
DOM + CSSOM → Render Tree.
Layout calculates position.
Paint draws pixels.
Composite combines layers.  

### Why doesn't the browser directly display HTML?

Because the monitor understands pixels, not HTML. The browser must convert HTML and CSS into a renderable representation before drawing pixels.

### Why is CSS converted into CSSOM?

To create a structured representation of styles that can be combined with the DOM to determine how elements should look.

### Reflow

Reflow is the process where the browser recalculates the size and position of elements because the layout has changed.

### What is Event Bubbling?

Event Bubbling is the default event propagation mechanism in the browser where an event starts from the target element and propagates upward through its ancestor elements until it reaches the document.

### What is Event Capturing?

Event Capturing is an event propagation phase where the event travels from the outermost element (document) down to the target element before the target handles the event.

### What is Event Delegation?

Event Delegation is a technique where a single event listener is attached to a parent element instead of multiple child elements. It relies on Event Bubbling, allowing the parent to handle events triggered by its descendants. This improves memory usage, performance, and works well with dynamically added elements.

When using Event Delegation, the parent receives the event.
