## Prototype

"A prototype is an object that JavaScript uses to share properties and methods between multiple objects. Instead of copying the same methods into every object, JavaScript stores them once in the prototype, which improves memory efficiency. Whenever an object doesn't have a property, JavaScript automatically looks for it in its prototype chain."

```
A Prototype is another object that stores shared properties and methods.
Instead of copying the same methods into every object, JavaScript lets
multiple objects share them through the prototype.
```

## Prototype Chain

- When a property or method is accessed, JavaScript first searches on the object itself.
- If it's not found, JavaScript automatically follows the prototype link and continues searching until it finds the property or reaches null.

## **proto**

"**proto** is a property available on objects that provides access to the object's internal prototype ([[Prototype]]). JavaScript uses this prototype link during property lookup. Although **proto** is still supported, Object.getPrototypeOf() is the recommended way to access an object's prototype."

- **proto** is a way to access an object's internal [[Prototype]].
- **proto** → mostly used for learning, debugging, or older code.
- Object.getPrototypeOf() → preferred in modern JavaScript.

```

| `prototype`                    | `__proto__`                     |
| ------------------------------ | ------------------------------- |
| Exists on functions            | Exists on objects               |
| Used when creating new objects | Points to an object's prototype |
| Shared methods are stored here | Used during property lookup     |

```

### Does every function have a prototype?

Every normal function has a prototype property. Arrow functions do not because they cannot be used as constructors with new.

### Prototype inheritance

Prototype inheritance is JavaScript's mechanism where one object can access the properties and methods of another object through the prototype link. Instead of copying methods, JavaScript links objects together and uses the prototype chain to look up properties when needed.

- Prototype inheritance creates a relationship between objects.
- The prototype chain is used to search for properties.

```
| `hasOwnProperty()`         | `in` Operator                     |
| -------------------------- | --------------------------------- |
| Checks only own properties | Checks own + inherited properties |
| Ignores prototype chain    | Follows prototype chain           |
```

### Why does JavaScript use prototypes?

JavaScript uses prototypes to allow multiple objects to share common properties and methods instead of creating duplicate copies for every object. This improves memory efficiency, promotes code reuse, and makes applications easier to maintain. JavaScript's inheritance model is prototype-based, and even ES6 classes are built on top of prototypes internally.

### Polyfill

A polyfill is a custom implementation of a JavaScript feature that is added when the environment doesn't support that feature. It helps older browsers provide the same functionality as newer JavaScript versions. Polyfills are usually added to built-in prototypes so that the feature behaves like a native method.
