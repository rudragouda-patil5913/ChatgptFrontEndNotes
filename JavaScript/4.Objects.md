# Objects
- Objects are mutable by default.
- Dot notation is used for known property names.
- Bracket notation is useful for dynamic property names.
- Object properties can contain primitives, objects, arrays, and functions.
- Objects can be nested.
- Object literals create a new object.

#### Object.hasOwn()
Checks whether a property belongs directly to the object.

Why not just use in?

```
in → own + inherited properties.
Object.hasOwn() → own property only.
```


#### Object.freeze()
Freezing makes the object's existing properties effectively read-only and non-configurable.
- Useful when you want a configuration object that shouldn't be changed.
The object can't be:
- Modified
- Extended
- Deleted from

#### Object.seal()
Sealing prevents adding and deleting properties, but existing properties can still be modified.
- Useful when you want the object's structure fixed, but values can still change.

#### Object.assign()
Object.assign() is mainly used to copy/merge properties from one or more objects into another object.

Object.assign() modifies the target object and returns that same target object.

```
const target = {
    name: "Rudra"
};

const source = {
    age: 28
};

const result = Object.assign(target, source);


target ─────► { name: "Rudra", age: 28 }
result ─────► same object
```

#### Object.assign(target, source)

1. Copies properties from source → target
2. Mutates the target
3. Returns the target
4. Later sources overwrite earlier properties
5. Copying is shallow


### What is Object.create()?
Object.create() creates a new object and sets its prototype to the object passed as an argument. Unlike the new keyword, it doesn't call a constructor function. It simply establishes the prototype relationship.

```
| `new`                                       | `Object.create()`                     |
| ------------------------------------------- | ------------------------------------- |
| Uses a constructor function                 | Uses an existing object as prototype  |
| Executes the constructor                    | Doesn't execute any constructor       |
| Initializes properties inside constructor   | You add properties manually           |
| Automatically links to `Function.prototype` | Directly links to the object you pass |
```



#### const Doesn't Make Objects Immutable
const prevents reassignment of the variable, not modification of the object.

#### Shallow Copy
A shallow copy creates a new top-level object but does not recursively copy nested objects.
```
const copy1 = { ...original };
const copy2 = Object.assign({}, original);
```

#### Deep Copy
A deep copy creates independent copies of nested objects too.
