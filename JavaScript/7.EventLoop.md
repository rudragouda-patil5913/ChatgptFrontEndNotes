### Why is JavaScript single-threaded?
JavaScript was designed as a single-threaded language to simplify programming and avoid race conditions while manipulating the DOM. Since only one piece of JavaScript executes at a time, multiple scripts cannot modify the webpage simultaneously, making browser behavior more predictable.

Because JavaScript was originally designed for browsers, where multiple threads modifying the DOM simultaneously could cause race conditions and unpredictable behavior. A single-threaded model keeps DOM manipulation simple and predictable.

### What is the Browser Runtime?
The Browser Runtime is the environment that executes JavaScript. Besides the JavaScript engine, it provides APIs such as timers, networking, DOM events, rendering, and storage. JavaScript itself is single-threaded, while the browser handles asynchronous operations and notifies JavaScript when they are complete.

### CallStack?
The Call Stack is a LIFO data structure used by the JavaScript engine to manage function execution. Every function call is pushed onto the stack, and once the function finishes execution, it is popped off the stack. This allows JavaScript to keep track of the current execution context and know where to return after a function completes.
